# 목운중학교 3학년 7반 학부모 의견 수합

화면은 GitHub Pages에서, 데이터는 선생님의 구글 스프레드시트에 저장됩니다.

| 파일 | 어디에 두나요 |
|---|---|
| `index.html` | GitHub 저장소 (공개되어도 괜찮은 화면 파일) |
| `Code.gs` | Google Apps Script에만 붙여넣기 (**GitHub에 올리지 마세요**. 학부모 번호 뒷자리가 들어 있어요) |
| `README.md` | 이 안내문 (GitHub에 올려도 괜찮아요) |

## 왜 구글 시트인가요?

GitHub Pages는 화면만 보여 줄 수 있어서 데이터를 저장할 곳이 따로 필요해요. 구글 시트를 쓰면 무료이고, 학부모 응답을 시트에서 바로 확인하거나 엑셀로 내려받을 수 있어요. 비밀번호와 학부모 번호 뒷자리는 구글 서버 안에만 있고 웹페이지 코드에는 들어가지 않기 때문에, 누군가 페이지 소스를 열어 봐도 알 수 없어요.

## 1. 구글 시트와 서버 만들기

1. [Google 스프레드시트](https://sheets.new)에서 빈 시트를 만들고 이름을 `3-7 의견 수합` 정도로 바꿔요.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 편집기에 있던 내용을 모두 지우고 `Code.gs` 내용을 통째로 붙여넣은 뒤 저장(💾)해요.
4. 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 눌러요.
   - 처음에는 권한 확인 창이 떠요. 본인 계정 선택 → ‘고급’ → ‘(프로젝트 이름)(으)로 이동(안전하지 않음)’ → ‘허용’을 누르면 돼요. 본인이 만든 스크립트라서 이런 안내가 뜨는 것이에요.
5. 시트로 돌아가면 `학생명단`, `조사목록`, `응답` 탭이 생겨 있어요.

## 2. 관리자 비밀번호 설정하기

1. Apps Script 편집기 왼쪽의 **⚙️ 프로젝트 설정**을 눌러요.
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**를 눌러요.
3. 속성: `ADMIN_PASSWORD` 값: 원하는 비밀번호 (8자 이상 권장) → **스크립트 속성 저장**.

비밀번호를 바꾸고 싶을 때는 같은 곳에서 값만 고치면 바로 적용돼요. 다시 배포할 필요는 없어요.
비밀번호를 5번 틀리면 10분 동안 잠기고, 로그인은 6시간 유지돼요.

## 3. 웹 앱으로 배포하기

1. 편집기 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 유형 선택(⚙️) → **웹 앱**.
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**로 설정하고 **배포**.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

> `Code.gs`를 나중에 고쳤다면 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 해야 반영돼요. (URL은 그대로예요.)

## 4. 화면에 서버 주소 넣기

`index.html`을 메모장 등으로 열어 아래 줄을 찾아 따옴표 안에 복사한 URL을 붙여넣어요.

```js
const API_URL = "https://script.google.com/macros/s/....../exec";
```

URL을 비워 두면 저장되지 않는 미리보기 모드로 열려요. (비밀번호 `demo`, 번호 뒷자리 `1234`)

## 5. GitHub Pages로 올리기

1. GitHub에서 **New repository** → 이름 예: `mokun-3-7` → Public → Create.
2. **Add file → Upload files**로 `index.html`(과 `README.md`)만 올리고 **Commit changes**.
3. 저장소 **Settings → Pages** → Branch를 `main` / `(root)`로 고르고 **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/mokun-3-7/` 주소로 열려요. 이 주소를 학부모님께 안내하면 돼요.

## 사용 방법

- **추가**: 주제, 내용, 형식(동의/미동의, 선택형, 단답형), 진행중/마감 상태를 정해요. 선택형은 ‘여러 개 고를 수 있게 하기’를 켜면 복수 선택이 돼요.
- **편집**: 카드마다 ‘수정’, ‘삭제’ 버튼이 나타나요. 조사를 마감하려면 수정에서 상태를 ‘마감’으로 바꿔요.
- **초기화**: 두 번 확인한 뒤 모든 조사와 응답을 지워요. 학생 명단은 남아요.
- **응답 확인**: 조사 화면 아래 ‘선생님: 응답 내용 보기’를 누르면 요약과 학생별 응답이 보여요. 구글 시트의 `응답` 탭에서도 볼 수 있어요.
- 학부모는 같은 조사에 다시 들어가 번호를 입력하면 제출한 의견을 고칠 수 있어요. 번호를 5번 틀리면 그 학생은 10분 동안 잠겨요.

## 새 학기에 반이 바뀌면

1. 사이트에서 **초기화**로 지난 조사를 지워요.
2. `Code.gs` 위쪽 `STUDENTS` 목록을 새 반 학생으로 바꾸고 **setup**을 다시 실행해요. (또는 `학생명단` 탭을 직접 고쳐도 돼요. 번호 뒷자리가 0으로 시작해도 그대로 유지돼요.)
3. 제목의 반 이름은 `index.html`의 `<title>`과 `<h1>`을 고쳐요.
